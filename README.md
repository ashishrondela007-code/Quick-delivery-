# Quick Delivery

Flutter grocery shopping app for Android and iOS.

## Current starter features
- Grocery home screen and delivery target banner
- Product categories and working product search
- Sample products with INR prices
- Add/remove product quantities
- Cart with subtotal

## Project setup
This repository contains the Flutter app source. To create platform folders and run it, install Flutter SDK, then run:

```bash
flutter create .
flutter pub get
flutter run
```
